# Frontend Animation Reference

## anime.js (juliangarnier/anime)
Lightweight JS animation library (17KB vs Framer Motion ~136KB). 

For any web-facing MahlanyaRPG UI (e.g., game launcher, lore browser):
- Use anime.js for UI transitions instead of Framer Motion
- Key APIs: anime.timeline(), anime.stagger(), CSS property animation
- ES module import: `import anime from 'animejs'`
